## Algorithm

This repository contains the source code for AI Assignment #2. The chosen algorithm is a **Bayesian Convolutional Neural Network with Monte Carlo (MC) Dropout** for image classification on the MNIST dataset.

MC Dropout, introduced by Gal & Ghahramani (2016), provides a lightweight yet principled way of obtaining approximate Bayesian uncertainty from a standard deep network. Instead of training a separate Bayesian model, we keep dropout active at test time and average predictions over multiple stochastic forward passes. This is mathematically equivalent to approximate variational inference in a deep Gaussian process.

## Main Results

| Metric | Value |
|--------|-------|
| Test accuracy | **99.25%** (9,925 / 10,000) |
| Training time | ≈164 seconds (CPU only) |
| MC Dropout samples (T) | 50 |
| Total parameters | 225,034 |
| Mean predictive entropy — correct | 0.0717 nats |
| Mean predictive entropy — incorrect | 0.9722 nats |
| Mean mutual information — correct | 0.0330 nats |
| Mean mutual information — incorrect | 0.4395 nats |

Incorrectly classified images show substantially higher uncertainty, confirming that MC Dropout captures meaningful model uncertainty.
